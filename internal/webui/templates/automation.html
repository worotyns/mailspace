The configured provider receives the selected fields and the first 512 bytes of each Space description. OpenRouter is an external service. Automatic classification excludes encrypted messages, attachments and browser-decrypted content. The secure reader has a separate, per-excerpt consent action; its results always require approval. Only incoming, supported cached mail is eligible for the worker. Manual assignments win. The worker makes up to three new requests per minute per enabled user; manual requests share a limit of six attempts per minute. Model usage may incur charges. Configure provider spending limits before enabling automatic mode.

Saving starts a new settings version and allows eligible messages to be evaluated again. Off stops future work; already submitted provider requests cannot be recalled.

Decision trace

Only source/Space references, versions, proposed ids, confidence and state are retained. No prompts, mail bodies, model explanations or raw responses. Replay validates the saved result without a new model call. Apply approves a saved proposal and protects it as a manual decision.
