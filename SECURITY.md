# Security

Mailspace is an early-alpha self-hosted mail client for controlled testing. It has not received an independent security audit. Known scope and compatibility limitations are recorded in [release readiness](docs/RELEASE_READINESS.md).

Please report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/worotyns/mailspace/security/advisories/new). Do not put credentials, private keys, passphrases, real mail, personal data or exploitable production details in public issues. If private reporting is unavailable, contact the maintainer through an established private channel before sharing sensitive details.

There is no guaranteed response time or supported-production-version policy yet. Include the affected commit, a minimal synthetic reproduction and the expected impact. The [threat model](docs/THREAT_MODEL.md) documents intended trust boundaries; it is not an audit attestation.
