# Everyday workflow

- **Spaces:** click a Space chip on a message to add/remove it directly. One message can belong to several Spaces. Selected chips have a checkmark. Status labels are independent of Spaces: create/edit them in Settings, filter with the label icon, and assign them to a message or cached thread/person scope. User-defined labels also have sidebar quick filters and compact per-message badge popovers; they never override Decision Model assignments.
- **Threads:** Show thread opens a side drawer. Reply there continues the selected original email thread, never a fabricated Space-wide recipient group. Escape or Close thread returns to the timeline. The preview covers up to 100 cached messages.
- **Archive:** Archive in Mailspace hides mail from active views without deleting originals or changing provider folders. Archived and All activity retain access; Restore reverses it and keeps Space assignments. Manual organization remains authoritative after restore.
- **People:** the modal shows 50 cached correspondents per page with search and Previous/Next. Only six shortcuts appear in the sidebar. Archived incoming mail does not contribute to active contacts. New email in a person scope prefills that address; recipient suggestions are limited to 20 cached matches. This does not download a remote address book.
- **Colors:** 16 named radio swatches support mouse, touch and native keyboard arrows. Other selects keep the native Safari/iOS picker.
- **Attachments:** click Attachments on ordinary mail to discover/download local files. Eye and download icons keep actions compact. PNG/JPEG attachments and CID images reveal inline on explicit request (4 MiB, 4096 per dimension, 16 MP); UTF-8 text/JSON up to 256 KiB uses a local text dialog. Remote images remain blocked. Other formats download. For encrypted mail use Decrypt / preview; file bytes stay in the browser. Full-message reading also shows attachments. Attachment-only views do not claim signature verification; open the full reader for it.
- **Commands:** Cmd/Ctrl K opens a searchable action list; Arrow Up/Down navigate results; Tab/Shift Tab and Enter activate normal controls, Escape closes. The menu links to Unsorted, All activity, Archive, compose, People, rules, automation and settings. It does not intercept plain typing or IME composition.
- **Jev:** Check Space suggestions displays the latest recorded overall confidence and suggested Spaces next to the message. It is not a separate probability for each Space and saved results may be stale. Review/apply uses the current revision/ownership/manual checks. From Commands, Preview up to 3 unassigned checks only eligible cached ordinary mail using existing saved consent. Preview remains dry-run even in Auto mode. The separate Check using saved mode action uses Manual (preview), Review (proposal) or Auto (apply at confidence ≥80%) exactly as configured; it never enables Auto by itself. Stored matching attempts are reused; updating Space definitions/settings allows a new decision. A command has a 30-second deadline and may complete fewer than three checks. No unlimited scan, plaintext fallback or encrypted-message batch.
- **History limits:** the decision screen shows the latest 50 runs, storing at most 5,000 per user. Local rule previews show at most 50 matches and rules apply at most 50 new decisions/pass. Cache/import limits remain in SERVER_SETUP.md.

Before upgrading to schema 12, back up SQLite and the installation credential keyring. Restore a pre-upgrade database and matching image for rollback. Browser key/draft exports remain separate.

Settings, key setup and full composition open in a trusted application panel. Key setup separates your private sending key from recipient public keys; verify both bindings before Encrypt & sign. The full composer also offers Sign only (unencrypted) after separate readable-content consent; encrypted originals cannot use it. Memory-only shared-worker unlocking is implemented under ADR-0032, with a page-local fallback and no reload-lifetime guarantee. Encrypted sending keeps the current view and provides a toast with Outbox details rather than navigating away. Server acceptance is not delivery confirmation.

A single date selects one local calendar day; an optional end date selects an inclusive range in your configured timezone. Consecutive lines starting with `>` (including `>>`) fold into native details controls; replies between quotes remain visible. The original MIME is unchanged.

Archive a thread or mail with a person from Commands: review the cached selection first (500 messages maximum per pass). Labels support the same scopes, including archived mail. Decision trace supports Accept selected / Accept all shown for up to 50 saved actionable proposals; outdated results are skipped, never silently forced or reclassified.

Search and combined rules share AND/OR conditions: e.g. `(subject:invoice OR subject:receipt) AND domain:example.test`. Use the adjacent rule icon to draft a disabled rule from search/person scope; date/label filters are excluded. Details and limits: [Local rules](RULES.md).


Full reply composition offers Quote original locally for the selected cached message (32 KiB text limit). It does not copy attachments or upload plaintext. Decrypted quotes require encryption even after reopening an encrypted local draft. The original signature state is shown; restored drafts make no fresh signature claim. Version-2 local drafts require a current compatible build, and an older reply draft conservatively keeps encryption required.


Send certainty appears in the upper-right message header, outside Space controls, with accepted/pending/uncertain text and distinct icons. Acceptance still means SMTP acceptance, not confirmed delivery. Settings calls the classifier section Decision Model; existing configuration variable names stay compatible.


The root feed initially shows the latest 20 authorized matching cached messages, newest at the bottom. Scroll upward near the top to prepend another 20; Load 20 older messages also works by keyboard and has a full native-page fallback. A retained message keeps its viewport position and mounted body/draft. Latest messages restarts the view when a cached anchor is no longer available. The end marker means the start of the current bounded cache, not all provider history. Sidebar counts and bulk/rule/People scopes stay unchanged; original-thread drawers retain their existing separate cap.
