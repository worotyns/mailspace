# Everyday workflow

- **Spaces:** click a Space chip on a message to add/remove it directly. One message can belong to several Spaces. Selected chips have a checkmark. Labels have been retired from the UI; existing stored label data is preserved.
- **Threads:** Show thread opens a side drawer. Reply there continues the selected original email thread, never a fabricated Space-wide recipient group. Escape or Close thread returns to the timeline. The preview covers up to 100 cached messages.
- **Archive:** Archive in Mailspace hides mail from active views without deleting originals or changing provider folders. Archived and All activity retain access; Restore reverses it and keeps Space assignments. Manual organization remains authoritative after restore.
- **People:** the modal shows 50 cached correspondents per page with search and Previous/Next. Only six shortcuts appear in the sidebar. This does not download a remote address book.
- **Colors:** 16 named radio swatches support mouse, touch and native keyboard arrows. Other selects keep the native Safari/iOS picker.
- **Attachments:** click Attachments on ordinary mail to discover/download local files. Preview supports UTF-8 text/JSON up to 256 KiB and PNG up to 4 MiB, 4096 per dimension and 16 MP. Other formats download. For encrypted mail use Decrypt / preview; file bytes stay in the browser. Full-message reading also shows attachments. Attachment-only views do not claim signature verification; open the full reader for it.
- **Commands:** Cmd/Ctrl K opens a searchable action list; Arrow Up/Down navigate results; Tab/Shift Tab and Enter activate normal controls, Escape closes. The menu links to Unsorted, All activity, Archive, compose, People, rules, automation and settings. It does not intercept plain typing or IME composition.
- **Jev:** Check Space suggestions displays the latest recorded overall confidence and suggested Spaces next to the message. It is not a separate probability for each Space and saved results may be stale. Review/apply uses the current revision/ownership/manual checks. From Commands, Preview up to 3 unassigned checks only eligible cached ordinary mail using existing saved consent. Preview remains dry-run even in Auto mode. The separate Check using saved mode action uses Manual (preview), Review (proposal) or Auto (apply at confidence ≥80%) exactly as configured; it never enables Auto by itself. Stored matching attempts are reused; updating Space definitions/settings allows a new decision. A command has a 30-second deadline and may complete fewer than three checks. No unlimited scan, plaintext fallback or encrypted-message batch.
- **History limits:** the decision screen shows the latest 50 runs, storing at most 5,000 per user. Local rule previews show at most 50 matches and rules apply at most 50 new decisions/pass. Cache/import limits remain in SERVER_SETUP.md.

Before upgrading to schema 10, back up SQLite and the installation credential keyring. Restore a pre-upgrade database and matching image for rollback. Browser key/draft exports remain separate.
