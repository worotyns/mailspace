# ADR 0006: Go templates + HTMX + Tailwind, conversation-first

Status: accepted · 2026-11-12 · Supersedes: ADR-0004 i frontend z ADR-0001.

## Kontekst

Użytkownik uznał pierwotny UI za zbyt daleki od Slack-like conversation approach i polecił przejście na Go+HTMX oraz lekki własny CSS na bazie Tailwind. To jawna zmiana wcześniejszego wyboru Mantine i zakazu Tailwind.

## Decyzja

Go html/template renderuje shell i fragmenty, HTMX zapewnia progressive enhancement, Tailwind CLI kompiluje CSS. Tabler SVG jest lokalnym sprite. Node wyłącznie na etapie build; assety osadzone w Go binary. Układ: workspace sidebar/channels, strumień wiadomości, panel thread, klasyczny fallback. Wszystkie główne linki mają normalny href i adresowalny stan URL.

HTMX nie wykonuje eval/script fragments i nie cache'uje historii. CSP pozwala wyłącznie lokalne scripts/styles. Decrypted plaintext i klucze nadal tylko w kliencie: przyszły JS crypto island poza serializacją/DOM processing HTMX. Zmiana renderowania nie zmienia threat modelu ani zakazu server decrypt/export.

## Konsekwencje

Mniej runtime JavaScript i brak SPA API plumbing. Niewielki własny CSS i templates wymagają spójnych tokenów i review. Bogatsze funkcje crypto potrzebują lokalnego JS, którego HTMX nie zastępuje. React/Mantine usunięte z zależności i z aktywnych instrukcji. Seed pozwala oceniać UX bez prawdziwych skrzynek.
