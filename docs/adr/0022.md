# ADR-0022 — Optional Litestream sidecar for SQLite replication

Status: Accepted.

Default Compose has no backup process. Explicit overlay and replica URL start pinned Litestream 0.5.18 alongside one app instance with the same non-root data-volume owner. Runtime target excludes Litestream. Backup credentials go only to sidecar. No metrics/MCP listener. Configuration uses one-second replica sync and periodic retained snapshots; operators must monitor lag and drill restore.

SQLite replication does not back up installation credential keys, browser keys/drafts or configuration. Preserve those separately, including keyring rotations. Local file replicas do not survive host loss. Off-host private storage/access policy/encryption is operator-managed; no client-side encryption claim. Restore to a fresh volume with matching keys/version; no destructive automatic restore over current state and no down-migration. Keep offline complete backups for rollback.

Upstream binary is Apache-2.0; its license is included. Native macOS SQLite and Linux-container SQLite must not be mixed for replication QA: verify within one Linux VM/filesystem. Container/replica availability is not proof of recoverability.
