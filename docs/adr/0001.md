# ADR 0001: Modularny monolit i storage

Status: accepted (design) · 2026-11-11

## Kontekst

Self-hosting ma działać bez zestawu usług.

## Decyzja

Go backend, Go templates + HTMX + Tailwind frontend (zmiana ADR-0006); SQLite default, PostgreSQL opcjonalny adapter po M1. Jeden deploy z bundlowanym UI. IMAP/SMTP źródłem poczty; baza projekcją i konfiguracją.

## Konsekwencje i alternatywy

Prosty deploy i testy, ale jawne granice modułów są odpowiedzialnością review. SQLite ogranicza skalowanie wieloprocesowe. Odrzucono mikroserwisy, własny mailserver i obowiązkowy Postgres.
