# ADR-0039: Compact local image previews and attachment controls

Status: accepted. Extends only the local image portion of ADR-0029. The owner requested local attachments/CID images, explicitly excluding remote images.

Attachment/CID PNG and ordinary baseline/progressive 8-bit JPEG images can be revealed inline beside their message's attachment controls after an explicit eye-button action. CID is only a local MIME attachment classification: it is not resolved through an arbitrary URL, injected into the HTML preview iframe or fetched remotely. Downloads remain explicit local Blob links. Unsupported image formats, HTML/SVG/PDF and other documents remain downloadable without execution. Text/JSON still uses a native dialog with textContent.

Image bytes are limited to 4 MiB, 4096 pixels per axis and 16 MP. PNG signature/IHDR and JPEG SOF dimensions are checked before an image Blob URL is created. JPEG header scanning is capped at 64 KiB and admits only supported 8-bit frames; malformed, unknown and out-of-bounds headers fail closed. Native decode/load errors are visible and the decoded dimensions are rechecked. These checks complement the browser codec, not an independent image-decoder audit.

The parent reader/timeline's reviewed img-src blob: exception remains unchanged. The mail HTML sandbox still has no image/resource permissions. There is no remote loader, backend image proxy, decrypted image upload, new attachment storage or dependency. Image URLs are created only on request, revoked on hide/clear/disposal, and stale image events cannot recreate a cleared preview. Downloads and image controls use the existing locally bundled Tabler icons with explicit accessible names; no mail-supplied SVG is used.

Send certainty now appears in the message header, outside horizontally scrolling Space controls. Accepted means server acceptance, not delivery; pending and uncertain/rejected outcomes use distinct non-success icons and text. Decision Model is the user-facing settings label; provider/environment/API identifiers remain compatible.

No migration is needed. Rollback restores modal PNG-only presentation and retains mail/vault/storage unchanged. Regression tests cover dimension limits, hostile/unsupported input, request-only inline rendering, object-URL cleanup, stale callbacks and header status placement. Manual mobile/desktop/keyboard acceptance remains with the owner on request.
