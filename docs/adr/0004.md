# ADR 0004: Mantine i minimalny własny UI

Status: superseded by ADR-0006 · 2026-11-11

## Kontekst

UI ma być estetyczne i spójne przy minimalnej liczbie własnych komponentów/CSS.

## Decyzja

Mantine dla komponentów, theme, layouts, forms i overlays; Tabler dla ikon. Brak własnego CSS w scaffold. Komponenty domenowe tylko dla zachowania pocztowego.

## Konsekwencje i alternatywy

Shadcn rozważono, ale vendoring komponentów zwiększa ilość własnego kodu; nie mieszamy systemów. Dopuszczalne theme/styles API i uzasadniony lokalny CSS po wyczerpaniu biblioteki.
