# ADR-0023 — Local binary OpenPGP/MIME input

Status: Accepted. Extends ADR-0013 compatibility without a new server/export contract.

The browser MIME reader accepts MIME-decoded binary OpenPGP packets as Uint8Array, alongside armored input. Never decode binary ciphertext as UTF-8 or reconstruct packet bytes from text. Existing envelope/size/part-count bounds remain, and OpenPGP.js validates packets/authenticated encryption locally with unauthenticated-message support disabled. Outgoing mail remains armored for broad compatibility. No private key, decryption or new plaintext capability reaches Go.

Tests cover signed binary ciphertext in base64 and quoted-printable MIME, exact file octets/Unicode after decrypt, integrity failure and locked vault; GnuPG-generated binary signed/encrypted input is accepted by the app vault. This closes only the binary-input slice, not detached signatures, secure quotes or actual Thunderbird acceptance. No schema change; rollback keeps original ciphertext and browser vault exports unchanged.
