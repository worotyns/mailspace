# ADR 0003: Opcjonalne capabilities i contribution model

Status: accepted (design) · 2026-11-11

## Kontekst

AI i indeksowanie nie są warunkiem zwykłej poczty. Użytkownik nie chce publicznego ekosystemu pluginów.

## Decyzja

Wewnętrzne kontrakty w repo, built-in moduły po review, disabled default i brak efektów off. Fork → PR → review → merge. Nie ma loadera, publicznego SDK, marketplace ani ABI stability promise.

## Konsekwencje i alternatywy

Łatwiejszy security review i spójność, kosztem braku instalacji dowolnego pluginu. AI local/external i semantyka są osobnymi capabilities. JEV-like oznacza deterministyczny eval/trace/replay bez zależności od nieokreślonego JEV produktu.
