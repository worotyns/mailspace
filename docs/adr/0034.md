# ADR-0034: Inert readable message presentation

Status: accepted.

Ordinary cached message text and locally decrypted previews use the same bounded Markdown-token renderer. Marked 18.2.0 (MIT, pinned, no runtime dependencies or lifecycle scripts) provides tokens only. The application constructs a fixed set of DOM elements with text nodes; it never inserts parsed HTML. Raw HTML remains literal text. Images are text placeholders, links remain selectable text without navigation attributes, task markers are text rather than controls. No remote resource, form, script, iframe or new HTML sink is introduced.

Paragraph spacing removes excessive empty paragraphs; code blocks retain literal whitespace. Quoted blocks fold into native details. Input is capped at 128 Ki UTF-16 code units, rendered structure at 2048 nodes/tokens and depth 12, with inert plaintext fallback on limits or parser errors. Tables have additional row/column limits. Oversized inline previews visibly indicate truncation; full-message access remains available.

This changes presentation only. Original MIME, cached text, original-thread references, classifier input and signature verification bytes remain unchanged. Decrypted text stays in an hx-disabled client-owned DOM subtree and never enters attributes, hidden fields, HTMX payloads, history, the server or classifier automatically. Existing lock/visibility/disposal clearing applies. The approved sanitized HTML preview iframe remains the separate ADR-0015 boundary.

The build bundles the pinned parser locally and includes its upstream license in THIRD_PARTY_NOTICES. Regression tests cover literal hostile HTML, resource/navigation exclusion, quote folding, code whitespace, bounded rendering and one-time enhancement. Rollback removes the display enhancer and parser dependency without a database migration.
