# ADR-0024 — Detached OpenPGP/MIME verification in the local reader

Status: Accepted. Extends ADR-0013/0023 for reading only; no signed-only submission contract.

Multipart/signed is verified against its original first MIME entity octets, never a reserialized parsed message. A bounded browser locator requires a unique signed content type, OpenPGP signature protocol, unambiguous boundary and exactly two parts plus closing delimiter. The signature part is decoded through the existing bounded MIME parser. Noncanonical/ambiguous envelopes fail visibly; the reader does not repair bytes to obtain a green signature. Unsigned preamble/epilogue never enter the displayed signed entity.

OpenPGP.js performs detached verification with local public contacts only. No private-key unlock is required. Unknown key, invalid signature, valid untrusted signature and valid signature bound to the claimed sender stay distinct. This also handles a detached signed MIME entity inside decrypted content, preserving its client-decrypted provenance and existing no-export/lifecycle rules. No extra network request, key discovery or remote verification is introduced. Exact original source remains downloadable for unsupported layouts.

Tests cover original octets including headers/attachments, missing/extra boundary parts, injected preamble/epilogue, forged sender, unknown/untrusted keys and mutated signed bytes. GnuPG-produced detached signatures and the shipped reader event path are exercised separately. No claim of Thunderbird acceptance, signed-only compose, secure quoting or complete OpenPGP/1.0 readiness follows from this slice. No schema change or destructive rollback.
