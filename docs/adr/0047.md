# ADR-0047: Per-user read state for shared mail

Status: accepted for MS-010.

A teammate reading granted mail cannot set the owner's provider `\Seen` flag: a grant is read-only and the provider write path (ADR-0043) is owner-scoped. This ADR gives each teammate their own local read state for shared messages so the Unread view is meaningful without touching the owner's account, provider flags or view.

## Model

Migration 016 adds `shared_read_state(user_id, message_key, unread, updated_at)`, keyed by the opaque message key and scoped to one user. A missing row means "inherit the cached provider state", so existing shared mail starts exactly where the owner's mailbox is. Writing a row stores only that viewer's unread flag locally. The table holds no mail text, headers, ciphertext, keys or provider credentials.

## Behavior

`ListForViewer` and `ResolveForViewer` overlay the viewer's own rows for shared records, so the row indicator, the Unread filter and the unread count are per-user. The message read/unread toggle and the automatic-after-open call use the same `POST /messages/seen` action: owned mail keeps the provider flag path from ADR-0043, shared mail writes only the viewer's local row. The owner's cached flags, provider state and timeline are never changed by a teammate, and two teammates keep independent state. A teammate's state does not depend on the provider flag-write capability, so the local toggle still works when `MAILSPACE_IMAP_FLAG_WRITES=0`.

Sharing remains read-only: Space, label, archive, reply, assignment and download controls keep their existing gating. Revocation removes visibility immediately; leftover local rows are harmless and never grant access.

## Rollback

Migration 016 is forward-only; restore the pre-upgrade backup to roll back. Dropping `shared_read_state` returns shared mail to the cached provider state, and owned mail is unaffected. No provider flag, message, collection or grant row changes meaning.

## Remaining

Per-user labels/Spaces and assignment for shared mail, and separate send-as, stay separate slices with their own review.
