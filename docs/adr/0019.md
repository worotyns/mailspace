# ADR 0019: One product entrypoint, dialog presentation and original thread preview

Status: accepted · 2026-11-13. Supersedes the remaining legacy presentation/default-demo assumptions in ADR-0006/0011/0016.

Authenticated personal mode is the default runtime and Compose configuration. `/` renders the actual timeline including the first-run empty state. `/timeline` preserves allowed filter/reply context through a redirect; owned `/mail` bookmarks redirect with account scope, dropping retired view parameters. Classic/Conversation/Calendar pages, their renderer and unauthenticated UI demo are removed. Synthetic development uses the same authenticated product with loopback fixture providers. Domain MIME/reference helpers are not presentation modes.

A Space remains individual-message many-to-many storage. The dialog groups adjacent same-author, same-account/revision, same reference-topic messages within 15 minutes and the same local day. Own messages align separately. These are presentation runs, never synthetic email threads, new send targets, ACLs or shared memberships. Missing references never cause subject-based transport grouping.

View email thread is an addressable root query context. It starts from an authorized current source, conservatively links unambiguous cached Message-ID references across that account's folders/outbox, handles cycles and excludes other accounts/configuration generations. It does not download history, decrypt on the server or use subject similarity. At most 100 cached messages around the anchor are resolved with exact source authorization for text display. Missing/ambiguous ancestors and preview MIME limits remain visible constraints.

Reply in that view still selects one concrete original. The normal inline/plain or browser-encrypted path supplies References/In-Reply-To from that authorized source. Returning to the Space preserves its filters; choosing another Space/person/label exits thread context. Opening a thread never assigns it to a Space. A reply explicitly composed from a Space may assign that outgoing message there, not every other thread member.

Private Space/label removal has an explicit confirmation and CSRF/owner checks; it removes metadata/assignments, never remote mail. Operator-only local password recovery transactionally changes the password and revokes the target user's sessions. Per-user revocation supports safe backup restoration. Neither operation modifies provider/OpenPGP credentials. No new schema, external model or telemetry is added.

Compose persists DB and credential keyring in a stable named volume, binds only localhost, stops gracefully and has a liveness healthcheck. Public origin remains explicit HTTPS with Secure cookies; provider access remains an exact TLS endpoint allowlist. The canonical server runbook covers provisioning, actual mailbox setup, browser-key exports, offline backup/new-volume restore and matching-image rollback. No external release/public deployment is implicit in this work.
