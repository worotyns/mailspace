# ADR-0042: Compact Space picker and visible membership badges

Status: accepted for MS-022 implementation.

Every individual-message row keeps giving each message its own Space membership. The horizontal list of every Space as an always-expanded assignment control is replaced by the same compact native popover pattern already accepted for private labels (ADR-0033). This is a presentation change only: many-to-many membership, metadata-only mutation, current owner/source/revision checks and explicit human overrides are unchanged.

## Badges and scope

The compact summary shows assigned Space badges as colored chips plus one neutral `+` affordance. Outside a Space view (All activity, Unread, Unsorted, a person, a label, a query, archived) every assigned Space badge is shown. Inside one Space view the currently viewed Space is omitted because the view itself already states it; only the other assigned Spaces are badged. A message with no other assignment shows only the `+` affordance. Space names remain escaped template text and never become HTML.

The popover still lists every authorized Space of the account with its assigned/unassigned state, including the Space currently being viewed, so a human can explicitly add or remove any assignment. A missing or changed source fails as today; suggestions from the optional Decision Model keep their dashed `suggested-space` styling and confidence only inside the popover, and never auto-assign.

## Interaction and response contract

The owner-scoped, CSRF-protected `POST /collections/{id}/membership` metadata mutation remains the contract. An HTMX request whose target is the message's Space picker receives only that picker plus an out-of-band refresh of the sidebar Space counts, so the message body, browser-only decrypted content and any unsent draft stay mounted. After a successful toggle the popover reopens with focus on the changed badge. Without JavaScript or Popover support the native `details`/form disclosure and the native collection page remain the fallback.

The Space currently being viewed is not removed from the view immediately after its own badge is unchecked; the row remains until refresh or navigation. Preserving mounted content and drafts takes priority, matching ADR-0033. No provider folder, mail flag, model call, schema or storage change is introduced. Rollback restores the previous inline presentation and keeps all memberships unchanged.

Regression tests cover assigned-badge scope in All versus one Space, the preserved explicit toggles, scoped picker IDs, the out-of-band sidebar response, foreign/CSRF denial and that no private preview or composer content enters the response.
