# ADR-0020 — Bounded JEV proposals and deterministic Space assignments

Status: Accepted. Extends ADR-0016/0017. Schema migration 007.

Models propose existing Space IDs for one ordinary message; a deterministic transaction validates owner, source/account generation, definition/settings revisions, confidence and manual epoch. No model tool execution, mail sending or sharing capability exists. Adapter off means no client/worker. Per-user Off/Manual/Review/Auto and metadata/text consent bind to the exact destination/model. Provider changes disable earlier consent.

Trace stores references/revisions and constrained proposal, never bodies/headers/briefs/raw response. Stable attempt keys suppress duplicate provider calls; limits bound spend/storage. Auto threshold is 0.8; human approval remains explicit and protects future assignment. Replay is validation only. Disabled providers, invented IDs, cross-owner/stale decisions and manual overrides fail closed. Local and OpenRouter adapters use fixed/admin-selected endpoints, timeout and strict JSON; OpenRouter requests no-collection/ZDR/parameter support without weaker fallback.

SQLite 007 adds settings/runs. No destructive down-migration: rollback restores pre-upgrade DB and matching keyring/source into a fresh volume. Domain tests cover stale/manual/two-owner cases and disabled/automatic/dry-run behavior. Live paid provider availability is outside deterministic CI.

TypeSafe Jev is handled via the actual fixed OpenRouter Decisions endpoint, not chat-generated JSON: independent Noul question per Space, multi-membership at p>=0.5, proposal confidence=min(p for selected,1-p otherwise), requiring >=0.8 for automatic apply. Missing/extra/wrong/invalid probabilities fail closed. Ordinary models use a separate JSON-schema chat adapter; no protocol/model fallback. Provider name includes Decisions protocol version, invalidating prior chat-path consent. See the official OpenRouter Jev/Decisions docs linked from AUTOMATION.md. Protocol tests use documented synthetic responses; no live paid request is claimed.
