# ADR-0025 — Inbox-zero triage and explicit cached-mail classification

Status: Accepted. Extends ADR-0019/0020 without new storage or provider authority.

The root with no explicit filters opens incoming Unsorted mail. Sent/own messages never inflate the queue. Once incoming messages have Space memberships, the queue reaches an explicit inbox-zero state. All activity remains an explicit view, preserving original messages and memberships; no remote move/delete/archive occurs. Space dialogs and original email-thread references retain their existing semantics.

Eligible cached ordinary messages expose an explicit per-message Space suggestion preview, including historical or already manually organized messages. Each request still requires saved provider/payload consent, rate/capacity bounds and source ownership. Preview is a dry-run; it never overwrites manual choices or applies memberships silently. Repeated unchanged previews reuse a stored attempt. Encrypted selection retains ADR-0021's separate per-excerpt approval. Trace links target stable run anchors. This is classification of already cached originals, not an implicit full-history download or paid bulk job.

Ordinary full-reader navigation loads inert text directly; formatted HTML remains a separately opened sanitized sandboxed dialog. Encrypted mail still needs explicit local unlock/decrypt. No raw HTML becomes primary content or reaches server-rendered templates.

Tests cover own-message exclusion, retained all-activity access, manual-only historical previews, no side effects/rebilling and reader egress/lifecycle. No migration; rollback only restores the prior navigation defaults.
