# ADR-0021 — Explicit selected decrypted excerpt classification

Status: Accepted. Narrow exception to ADR-0002/0013, not a general export capability.

Automatic classifiers still exclude encrypted messages. In the typed secure reader only, after local decryption, a user may select/type up to 4 KiB, inspect the exact excerpt and displayed provider/model, and approve one request for Space classification. No full-message fallback, hidden named form/HTMX submission, private key, passphrase, attachment or original header upload is allowed.

Dedicated CSRF/Origin-protected JSON route resolves the owned encrypted source and checks current per-user provider consent. It relays that excerpt and Space briefs in memory using operator credentials; it never stores excerpt/content hash/prompt/raw response in DB, trace or logs. Rate/capacity limits apply. The 25-second request can be cancelled before send; already transmitted data cannot be recalled. The operator/proxy and provider become recipients of this selected plaintext. Their compromise/retention is a residual risk; do not claim backend blindness for this action. Browser close/lock/hidden lifecycle clears local selection. Provider routing policy is a request, not a privacy attestation.

Always dry-run; separate human approval applies IDs. Replay uses stored references without re-export. Generic provenance policy continues denying client-decrypted AI/index/webhook export, including global opt-in. No arbitrary endpoint/tools/send/share authority is introduced. Domain and browser egress tests verify exact payload/consent/no automatic apply/no plaintext persistence. No new storage fields for excerpts.
