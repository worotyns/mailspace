# ADR 0002: OpenPGP i granice plaintext

Status: accepted (design) · 2026-11-11

## Kontekst

Prywatność nie może zależeć od dyscypliny każdego opcjonalnego modułu.

## Decyzja

Crypto i key vault tylko w kliencie, OpenPGP/MIME, original MIME bytes, provenance i fail-closed policy. Server nie przyjmuje private keys/passphrase/decrypted content. Desktop hardware bridge dopiero przez osobny ADR.

## Konsekwencje i alternatywy

Backend nie potrafi globalnie indeksować odszyfrowanej poczty. Browser jest zależny od uczciwego JS origin. Ewentualny jawny client export wymaga osobnego ADR, nie rozszerzenia ogólnego AllowExport.
