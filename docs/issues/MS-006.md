# MS-006: OpenPGP/MIME i bezpieczny composer

Etap: M2 · Priorytet: P0 · Zależności: 004,005 · Status: in progress

## Zakres

Decrypt/verify i encrypt/sign w browser; recipient trust, missing key, drafts, quotes, attachments.

## Kryteria odbioru

GnuPG/Thunderbird round-trip; canonicalization; corrupted sig; mixed recipients; ciphertext drafts; brak plaintext w API/DB/logs/trace; brak cichego downgrade.

## Definition of done

Kod, testy zachowania i błędów, brak wycieku między kontami, dokumentacja/capabilities zgodne z funkcją, mały reviewable commit. Sprawdź AGENTS.md; nie implementuj sąsiednich issue przy okazji.

## Integrated alpha slice

Browser signed encryption, explicit all-recipient trust, own Sent copy, wildcard Bcc key IDs, opaque MIME submission/outbox, local decryption/embedded-signature verification and local attachment downloads work in the current slice (ADR-0013). GnuPG, two-user HTTP/SMTP/Sent integration and a synthetic browser round-trip are covered. Full issue remains open: detached signatures, binary/legacy layout compatibility, secure quotes and Thunderbird matrix. Local drafts/attachments are now implemented in ADR-0014.

Local ciphertext drafts (explicit save/load, no autosave/IMAP sync) and encrypted attachments (10 files / 1 MiB total) are implemented in the next slice, ADR-0014. Remaining: detached-signature read/send, binary/legacy variants, secure quote UX and Thunderbird matrix.
