## Per-user team state: read state (ADR-0047, schema 16)

Teammates keep their own local read state for shared mail in `shared_read_state`, overlaid on the timeline list/resolver. Owned mail keeps the provider `\Seen` path (ADR-0043); a teammate's toggle or automatic open never changes the owner's provider flags, cached state or view, and two teammates stay independent. Read state is local metadata only and does not depend on the provider flag-write capability. Remaining: per-user labels/Spaces and assignment for shared mail, and separate send-as.
