# MS-008: Renderer i attachments security

Etap: M2 · Priorytet: P0 · Zależności: 003,006 · Status: in progress

## Zakres

Text default; sanitizacja i izolowany HTML, zewnętrzne obrazy off, safe downloads.

## Kryteria odbioru

Malicious HTML/MIME corpus bez requestów sieciowych/skryptów; CSP; attachment ACL; limity dekompresji i MIME nesting.

## Definition of done

Kod, testy zachowania i błędów, brak wycieku między kontami, dokumentacja/capabilities zgodne z funkcją, mały reviewable commit. Sprawdź AGENTS.md; nie implementuj sąsiednich issue przy okazji.

Text-first MIME and explicit isolated HTML preview implemented in ADR-0015: native plain preferred, HTML-only converted; DOMPurify + empty sandbox srcdoc popup, no active resources/navigation. Owner-scoped raw reader supports ordinary local attachment downloads too. Encrypted HTML stays browser-only. Broader MIME/charset/CID compatibility remains part of the final security/compatibility gate.
