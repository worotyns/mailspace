## Local full-text index (ADR-0046, schema 15)

Plain word search now matches ordinary cached preview text through a local SQLite FTS5 index maintained by triggers, unioned with the legacy metadata substring match. Structured predicates keep their exact evaluation. Ciphertext, client-decrypted material, keys and credentials never enter the index, and the index is a lookup only, never authorization. Results are bounded and stay in chronological order; relevance ranking, snippets and model/semantic embeddings remain open.
