# MS-020: Message-level Spaces and unified timeline

Etap: core UX · Priorytet: P0 · Status: implemented for personal testing · ADR-0016/0017/0018/0019

## Scope

Spaces aggregate individual messages many-to-many. Original email references serve replies, never define a Space dialog. Primary navigation: Spaces, Unsorted, People and labels; one date-aware timeline. Provider folders/legacy views become an advanced fallback. Manual triage works without a provider. Reply inline to a visible selected original; encryption is an option with a small modal and no encrypted-source downgrade.

## Acceptance

- Messages from one original thread can occupy different Spaces; one message can occupy several.
- Source ACL/config revision/UIDVALIDITY checked on read/assign/reply. Membership never grants mail access.
- Names/descriptions editable; Payments/Commerce/Personal are optional development examples, not production defaults.
- Human assignment survives exact source copies/restarts; model responses cannot silently overwrite manual revisions.
- Outgoing entries appear with honest send certainty; original References and recipients preserved.
- Mobile/dark, independent scrolling, keyboard/date jump, empty/error states and inline reply feedback.
- No required model/index or fake connected provider. Optional JEV integration follows the manual workflow.

## Delivered foundation

Typed original source feed, private Space/label storage (migration v6), owner/current-source assignment checks, manual revisions and regression tests. Unified main timeline, private Space/label create/edit/manual per-message assignment, Unsorted/People/date filters, exact-source reader and inline ordinary replies are implemented. Encrypt switches the composer into a client-only mode; a compact modal unlocks a local key. The encrypted JSON allowlist accepts the typed original reference and optional private Space; parent references remain server-derived. Encryption errors never fall back to plaintext. Local lifecycle locking clears the client composer; submitted/uncertain sends do not auto-retry.

Limits: recent authorized cache (up to 1,000 consolidated entries, 100 outbox sources per account), metadata search, private collections only. The advanced reader/composer remains available for attachments and local drafts. No JEV/OpenRouter provider is connected. Team sharing, richer inline encrypted reading and the full crypto compatibility gate remain separate open work.

## Product consolidation

Root timeline, compact dialog runs, original cached thread view with selected-message replies, removal of legacy UI/default demo, Space/label removal and stateful server runbook are implemented. MS-007 decision providers and MS-009 team source ACLs remain independent open work. See RELEASE_READINESS.md; this issue does not close the full 1.0/security gate.
