# MS-001: Identity, SQLite i sesje

Etap: M1 · Priorytet: P0 · Zależności: M0 · Status: implemented (local validation; container validation pending CI)

## Zakres

Migracje users/sessions/accounts; opaque cookie session; CSRF/origin protection, logout/revoke, rate limits. Hasła przez utrzymywaną OSS bibliotekę Argon2id, brak własnej kryptografii.

## Kryteria odbioru

Dwa users; IDOR denied; restart zachowuje dane; migracja up/down lub udokumentowany forward restore; secure cookies i CSRF test; żadnych sekretów w logach.

## Definition of done

Kod, testy zachowania i błędów, brak wycieku między kontami, dokumentacja/capabilities zgodne z funkcją, mały reviewable commit. Sprawdź AGENTS.md; nie implementuj sąsiednich issue przy okazji.

## Wdrożone

CLI user add, Argon2id, SQLite migracja v1 i WAL, personal-mode login/session/logout/revoke-all, Origin+CSRF, secure cookies, bounded login limiter i owner-scoped account metadata. Testy obejmują dwóch userów, restart, offline restore, expired/revoked/rotated sessions i błąd starszej binarki dla nowszego schematu. Instrukcja: ../IDENTITY.md. Transport mail i credential store to MS-002.
