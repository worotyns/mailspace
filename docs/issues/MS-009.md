# MS-009: Team workspace i shared mailbox

Etap: M3 · Priorytet: P1 · Zależności: 001,006 · Status: organization foundation implemented; shared-mail scope planned

## Zakres

Role owner/member, osobiste konta vs wspólne, send-as osobno, audit bez treści.

## Kryteria odbioru

Deny-by-default dla private accounts; permissions na jobs/live events/attachment; usunięcie membership natychmiast odbiera sesji dostęp.

## Definition of done

Kod, testy zachowania i błędów, brak wycieku między kontami, dokumentacja/capabilities zgodne z funkcją, mały reviewable commit. Sprawdź AGENTS.md; nie implementuj sąsiednich issue przy okazji.

## Foundation delivered early

Profile/timezone, organizations, owner/member roster, active context, add/remove existing local users and metadata audit are implemented per user UI feedback. Membership never grants private mail access. Shared mailbox/send-as remain planned; OpenPGP dependency still applies to the secure shared-mail stage. ADR 0011 / SPACES.md.
